# DPI-диагностика на iPhone: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Обёртка над dpi-detector для a-Shell на iPhone: одна Команда запускает движок, показывает короткий отчёт с вердиктом и кладёт полный лог и JSON в iCloud Drive.

**Architecture:** Движок (чужой код, закреплён на коммите) пишет текстовый лог. Наш `report.py` разбирает лог в структуру, считает вердикт по строгим правилам, сравнивает с последним полноценным прогоном на той же сети и печатает сводку в файлы, которые забирает Команда. В a-Shell нет `fork`, поэтому движок и обёртка это две команды подряд в одной Команде.

**Tech Stack:** Python 3.8+ (только стандартная библиотека в обёртке), pytest для тестов на Mac, a-Shell mini и Команды (Shortcuts) на iPhone, dpi-detector v4.2.4.

**Spec:** `docs/superpowers/specs/2026-11-02-dpi-ios-design.md`

## Global Constraints

- Обёртка: только стандартная библиотека Python, синтаксис совместим с 3.8 (без `match`, без `X | Y` в аннотациях; `from __future__ import annotations` в каждом модуле).
- Движок закреплён: репозиторий `https://github.com/Runnin4ik/dpi-detector`, коммит `8d6d25a733f82e97a2aad8435072f8a1e3e43958` (версия 4.2.4). Движок не изменяется.
- Движок живёт в `../dpi-detector` относительно папки обёртки; на телефоне это `~/Documents/dpi-detector` и `~/Documents/dpiphone`.
- Режимы и тесты движка: `quick` = `-t 0123`, `full` = `-t 01235`, `sni` = `-t 34`. Параллельность `-c 20`.
- Команда запуска движка (одна строка, именно так): `python ../dpi-detector/dpi_detector.py -t <тесты> --batch -c 20 -o out/raw.log > out/console.log 2>&1`.
- Все тексты отчёта на русском. Структура короткого отчёта: строка вердикта, пустая строка, строки фактов.
- Имя файла в iCloud: `YYYY-MM-DD_HH-MM_<mode>_<net>.log` и `.json`; `net` очищено до `[A-Za-z0-9_-]`, пусто → `unknown`.
- Пороги правил вердикта живут в одном месте (`dpiphone/thresholds.py`) и только там.
- Коммиты на каждом шаге «Commit»; сообщения на русском, последняя строка `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. **Обрезанные имена доменов** в таблице движка (`media.discordapp.…`, `www.themoscowtime…`): парсер обязан восстановить полное имя по `domains.txt` движка, иначе сравнение «появилось/исчезло» будет врать на каждом прогоне. Тест в Задаче 2.
2. **Многострочные ячейки** таблицы TCP 16–20 КБ: статус `UNKNOWN` переносит хвост (`RemoteProtocolEr…`) на следующую строку в колонку «Статус». Парсер не должен принять хвост за отдельный статус или цель. Тест в Задаче 2.
3. **Лог без панели «Итог»** (движок упал или a-Shell усыплён): парсер отдаёт `complete=False`, вердикт только «не удалось», файл всё равно именуется и пишется. Тест в Задачах 2 и 5.
4. **Имя сети с пробелами, кириллицей и кавычками** (`Домашний Wi-Fi 5G`): имя файла и JSON корректны, команда в Shortcut не ломается. Тест в Задаче 5.
5. **Прогон под VPN как база**: после прогона с FakeIP следующий нормальный прогон не должен получить «появились новые блокировки». Тест в Задаче 4.

```python
@dataclass
class NetInfo:
    ipv4: Optional[str]; ipv6: Optional[str]
    org: Optional[str]; asn: Optional[str]      # asn как "AS197540"
    country: Optional[str]
    system_dns: List[str]; fakeip_system_dns: bool   # "(fake-ip)" у системного DNS

@dataclass
class DnsResult:
    doh_ok: int; doh_total: int; dot_ok: int; dot_total: int; udp_ok: int; udp_total: int
    hijacked_brands: List[str]; hijacked_all: bool     # строка «Подмена резолвера»: список, или «Все»
    subst_sub: int; subst_total: int                   # «Подмена ответов у 7/35 UDP»
    fakeip_sub: int                                    # «FakeIP ответов у N/M UDP», 0 если строки нет
    isp_intercept_warning: bool                        # «[!] Ваш интернет-провайдер перехватывает DNS-запросы»
    fakeip_warning: bool                               # «[!] DNS-ответы содержат FakeIP»

@dataclass
class DomainResult:
    domain: str; http: str; tls12: str; tls13: str; detail: str

@dataclass
class TcpTarget:
    id: str; asn: str; provider: str; status: str; detail: str
    @property
    def provider_group(self) -> str   # первое слово провайдера без знаков: "Hetzner Cloud 2" → "Hetzner"

@dataclass
class TelegramResult:
    download: str; upload: str          # ОК | ЗАМЕДЛЕНИЕ | ЗАМЕДЛЕНИЕ+ОБРЫВ | НЕДОСТУПНО | ОШИБКА
    dc_ok: int; dc_total: int

@dataclass
class SniResult:
    found_as: int; blocked_as: int
    per_provider: Dict[str, List[str]]  # провайдер → найденные SNI (пусто, если не найдены)

@dataclass
class RunResult:
    complete: bool                      # есть панель «Итог»
    net: Optional[NetInfo]
    dns: Optional[DnsResult]
    domains: Optional[List[DomainResult]]
    fakeip_domains: int                 # «Трафик перехватывается Fake-IP: у 36 доменов», иначе 0
    tcp: Optional[List[TcpTarget]]
    telegram: Optional[TelegramResult]
    sni: Optional[SniResult]

@dataclass
class Verdict:
    code: str      # no_data | vpn | dns_new | whitelist | dns_and_whitelist | new_blocks | channel | ok
    text: str
    facts: List[str]

@dataclass
class RunRecord:
    timestamp: str          # "2026-11-02T14:32:05" локальное время
    mode: str; net: str; net_raw: str
    engine_commit: str; wrapper_version: str
    result: RunResult
    verdict: Verdict
    base_timestamp: Optional[str]
    diff: Optional["Diff"]              # из compare.py, Задача 4
    valid_base: bool                    # complete и verdict.code не в (no_data, vpn) и mode != "sni"
```

Все dataclass'ы сериализуются `dataclasses.asdict` и восстанавливаются функцией `record_from_dict(d: dict) -> RunRecord` в `model.py`.

- Produces `dpiphone/buckets.py`:

```python
BLOCK = {"TLS RST","TCP RST","TLS ALERT","TLS BLOCK","TLS SPOOF","TLS EOF","TLS MITM",
         "TLS ABORT","TCP ABORT","BLOCKED","ISP PAGE","DNS FAKE","DETECTED"}
CHANNEL = {"TLS DROP","SYN DROP","TIMEOUT","READ TIMEOUT","SEND TIMEOUT","POOL TIMEOUT",
           "NET UNREACH","HOST UNREACH"}
def normalize(status: str) -> str   # strip, upper, без хвоста после "(" и после "…"
def bucket(status: str, detail: str = "") -> str   # "block" | "channel" | "noise"
```

`REDIR` → `block`, если `detail` содержит `→` (редирект на чужой домен), иначе `noise`. Всё, что не в BLOCK и не в CHANNEL, → `noise`.

- Produces `dpiphone/thresholds.py`: константы `WHITELIST_MIN_SHARE = 0.5`, `WHITELIST_MIN_PROVIDERS = 3`, `NEW_BLOCKS_MIN = 3`, `CHANNEL_MIN_SHARE = 0.25`, `NO_DATA_CHANNEL_SHARE = 0.5`, `DNS_SUBST_MIN_RESOLVERS = 2`.

Формат лога (см. `tests/fixtures/mac_vpn_quick.raw.log`), на который опирается парсер:

- Панель «Информация о сети и системе»: строки `IPv4: <ip>  Subnet: ...`, `IPv6: <ip>`, `Org: <org> (AS<n>)`, `Location: <флаг> <CC>`, `Системный DNS: <ip> (fake-ip)`. `IPv4: недоступен` → `ipv4=None`.
- Тест 1: предупреждения `[!] Ваш интернет-провайдер перехватывает DNS-запросы` и `[!] DNS-ответы содержат FakeIP`. Счётчики берутся из панели «Итог»: `DNS доступность    36/36 DoH  32/33 DoT  35/37 UDP` (DoT может отсутствовать), `Подмена резолвера  —` либо список через запятую либо `Все`, `Подмена ответов    у 7/35 UDP`, `FakeIP ответов     у N/M UDP`.
- Тест 2: таблица с заголовком `┃ Домен ┃ HTTP ┃ TLS1.2 ┃ TLS1.3 ┃ Детали ┃`, строки `│ amnezia.org │ OK │ OK │ OK │ 0.8s │`. Имя домена может быть обрезано с `…`: восстанавливается как единственный `known_domains`, начинающийся с обрезанного префикса; если кандидатов нет или больше одного, остаётся как есть. Строка-продолжение (первая ячейка пустая) дописывает свои непустые ячейки к предыдущей строке через пробел. После таблицы: `Трафик перехватывается Fake-IP: у 36 доменов`.
- Тест 3: таблица с заголовком `┃ ID ┃ ASN ┃ Провайдер ┃ Статус ┃ Детали ┃`, строки `│ OR-05 │ AS54253 │ Oracle 1 HTTP │ UNKNOWN │ Protocol error | │` с продолжениями, где ID пуст; продолжения склеиваются так же. `asn` хранится без `☆`.
- Тест 5: строки панели «Итог» `TG Скачивание    ОК               ср. 5.2 MB/s, 30.9 MB`, `TG Загрузка      ЗАМЕДЛЕНИЕ+ОБРЫВ ...`, `TG Датацентры    ОК 5/5`.
- Тест 4: строки `  <Провайдер> AS<n>  ✓ <sni> #12  <sni2> #40` и `  <Провайдер> AS<n>  × SNI не найден (все заблокированы)`, итог `Найдено белых SNI: у 5 из 7 заблокированных AS` или `Белые SNI не найдены ни для одной из 7 заблокированных AS` или `Ни одна AS не заблокирована — перебор SNI не нужен.` (тогда `found_as=0, blocked_as=0`).
- `complete = True`, только если есть строка `─ Итог ─`.

В `report.py` базой для `decide` служит `base_record.result`.
  - `blocked_domains(run) -> Set[str]` — домены, у которых хоть одна из трёх колонок в корзине `block`;
  - `channel_share(run) -> float` — доля целей тестов 2–3 (домен считается одной целью по худшей колонке) в корзине `channel`;
  - `detected_providers(run) -> Set[str]` — `provider_group`, у которых все цели `DETECTED`;
  - `dns_substituted(run) -> bool` — `hijacked_all` или `len(hijacked_brands) >= DNS_SUBST_MIN_RESOLVERS` или `subst_sub >= DNS_SUBST_MIN_RESOLVERS`.

Порядок правил и тексты (из спеки, раздел «Вердикт: правила»):

| code | условие | text |
|------|---------|------|
| `no_data` | `not complete`, или `net is None`/`net.ipv4 is None`, или `channel_share >= NO_DATA_CHANNEL_SHARE` и ни одной цели в `block` | «Сеть почти не отвечает, проверить не удалось» |
| `vpn` | `net.fakeip_system_dns` или `fakeip_domains > 0` или `dns.fakeip_warning` или (`base` есть и `base.net.asn != run.net.asn`) | «Похоже, включён VPN или прокси, прогон не о вашем операторе» |
| `dns_and_whitelist` | условия `dns_new` и `whitelist` одновременно | «Смешанная картина: подмена DNS и белый список» |
| `dns_new` | `dns_substituted(run)` и `base` есть и `not dns_substituted(base)` | «Оператор начал подменять DNS» |
| `whitelist` | `DETECTED` у `>= WHITELIST_MIN_SHARE` целей теста 3 и `len(detected_providers) >= WHITELIST_MIN_PROVIDERS` | «Похоже, включён белый список: обрываются <провайдеры через запятую>; в норме <провайдеры>» |
| `new_blocks` | `base` есть и `len(blocked_domains(run) - blocked_domains(base)) >= NEW_BLOCKS_MIN` | «Появились новые блокировки: <домены через запятую>» |
